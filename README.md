# Board Coordinates Trainer

A small HTML/CSS/JavaScript chessboard coordinate trainer.

- Press **Start**.
- A dot appears on a chessboard square.
- Type the coordinate, e.g. `e4`.
- Correct answers flash green and add 1 point.
- Score as much as possible in 30 seconds.

Open `index.html` in a browser, or serve locally:

```bash
python3 -m http.server 8080
```

Then visit <http://localhost:8080>.
